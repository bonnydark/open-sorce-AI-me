How can we help?

Quick guides for getting started, choosing the right AI module, managing your account, and understanding usage and API access.

1. Getting started

Open the GortGPT workspace and create an account or sign in. Your private conversations and account features require authentication.

  • Use an email address you can access and keep your password private.
  • Use the workspace settings to review available preferences and AI options.
  • Sign out on shared devices when you finish.

2. Chats and conversation history

Use a conversation for one topic and continue sending messages in that conversation to preserve its context. Start a new conversation when you want to switch topics.

  • Open a previous conversation from the history sidebar.
  • Refresh the page if a screen appears stale; if the issue persists, note the page URL and error message.
  • Only share a conversation when you intend other people with the link to view its contents. A share link is different from private chat history.
Do not put passwords, private keys, API secrets, or other sensitive information into a conversation or shared chat.

3. Choosing an AI module

Modules are designed for different workflows. Availability and output quality depend on the configured model and service.

  • AI / General: everyday questions, writing, and brainstorming.
  • Code Copilot: programming help, debugging, and code explanations.
  • Security Analyst: defensive security learning and analysis of authorized systems.
  • Study Tutor: explanations, revision, and guided learning.
  • Vision AI: questions about supported image attachments.
  • Gort: the project's configurable assistant module.

4. Agentic AI and multi-agent workflow

Choose Agentic AI · Plan & Act in Settings → Active AI module when you want the assistant to break a task into steps, use available read-only tools, and review the result.

  • Planner: breaks the goal into a short plan.
  • Researcher / executor: can perform up to four read-only tool steps using configured web search and public-page retrieval.
  • Reviewer: checks the collected evidence and prepares the final response.

Live search requires the administrator to configure BRAVE_SEARCH_API_KEY. If it is missing, the agent should report that search is unavailable rather than claim it searched.

This is a bounded MVP, not an unrestricted autonomous computer agent. It cannot sign in to Shopee/TikTok seller accounts, read private shop dashboards, change inventory, send customer messages, issue refunds, place orders, or run arbitrary code. Those actions require separately configured integrations, permissions, audit logs, and explicit approval before consequential actions.

5. Images and attachments

When image attachment controls are available in your workspace, attach a supported image and include a clear question about what you want analyzed. Image understanding depends on the selected module and configured model.

  • Use a common supported format such as PNG, JPEG, GIF, WebP, BMP, or AVIF.
  • If upload fails, try a smaller image and confirm the format is supported.
  • Remove personal or confidential details from images before uploading.

Do not assume that every file type can be analyzed just because it can be attached.

6. Memory and privacy

Where memory controls are available, review saved information and disable or remove items you no longer want used. Memory is context, not a guarantee that every detail will be remembered correctly.

  • Review account settings and memory controls periodically.
  • Never use memory as a password manager or secret store.
  • Before sharing a chat, check that it contains nothing private.

7. Usage limits and estimated costs

GortGPT applies a monthly account plan allowance to successful AI requests. Current plan limits are:

  • Free: 3,000 requests per UTC calendar month.
  • Pro: 6,000 requests per UTC calendar month.
  • Business: 20,000 requests per UTC calendar month.
  • The monthly allowance resets at the start of each UTC month. After it is exhausted, each further successful AI request uses one admin-granted bonus credit if available.
  • Each API token also has a separate configurable daily rate limit. That per-token cap applies in addition to the account plan allowance.
  • Cost figures are estimates from configured rates, not a provider invoice or guaranteed exact cost.
Never treat an estimate as proof of the exact amount charged by an external AI provider. Paid plan access is granted only after verified Stripe subscription events; the checkout page alone does not activate a plan.

8. API tokens — what they do and how to use them

An API token lets your own script, app, or bot send requests to GortGPT without signing in through the normal chat interface every time. It authenticates requests to GortGPT's API; it is not an OpenAI/provider API key and does not reveal the upstream provider's secret.

Create a token

  1. Sign in to the GortGPT workspace.
  2. Open Settings → Developer API tokens.
  3. Create a token, give it a clear name/purpose, and copy it. Store it somewhere private, such as an environment variable or secret manager.
  4. Open that token's usage page to review its limit, requests, estimated cost, and other usage details.

Use the token in a request

API base URL: https://openai.xzort.workers.dev/v1. Chat endpoint: POST /chat/completions. Add the token in the Authorization: Bearer header. Example using cURL:

curl https://openai.xzort.workers.dev/v1/chat/completions \
  -H "Authorization: Bearer $GORTGPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "code-copilot",
    "messages": [
      {"role": "user", "content": "Explain this code"}
    ]
  }'

Set GORTGPT_API_KEY in your terminal environment before running the example. Replace the model and message with your needs. Available model/module names are ai-engine, ai-agent, gort, code-copilot, security-analyst, study-tutor, and vision-ai. The current API supports text messages and non-streaming responses; image payloads and stream: true are not supported yet.

Manage token limits and usage

  • New tokens start with a limit of 100 successful API requests per day.
  • On a token's usage page, set its purpose and daily limit from 1 to 10,000 requests/day.
  • The token-specific limit resets at 07:00 Vietnam time (00:00 UTC), and your account-wide quota/bonus credits still apply too.
  • Review requests, input/output characters, and estimated costs on the token usage page. Cost and token-count figures are estimates, not an exact provider invoice.
  • Use Show token on the token's own usage page if you need to reveal it again. This requires the site's encryption secret to be configured; older tokens may need to be recreated.

Keep it safe

  • Never put a token in public GitHub code, frontend/browser JavaScript, screenshots, or public chats.
  • Never share the token with another user. Its usage consumes your account's allowance and may affect your costs.
  • If it leaks, revoke it immediately. Delete a revoked token only if you want to permanently remove it and its usage records.
  • The site administrator must configure the Cloudflare Worker secret API_TOKEN_ENCRYPTION_KEY with a stable value of at least 32 characters before encrypted token reveal can work. Do not share this secret.

For Python, Node.js, full request/response examples, and the latest API details, read the GortGPT API documentation on GitHub.

Treat API tokens like passwords. If you are only chatting on the website, you do not need to create an API token.

9. Troubleshooting

Login fails or the page signs me out

Check that cookies are enabled, reload the page, and sign in again. If the issue repeats, record the approximate time and the browser console/network error without sharing passwords or tokens.

Monthly plan limit reached

Check the usage and plan display. The account plan allowance resets at the start of each UTC month; bonus credits may cover additional requests. An API token can also reach its own separate daily limit.

API token encryption error

An administrator must set API_TOKEN_ENCRYPTION_KEY in the correct Cloudflare Worker environment as a secret of at least 32 characters. Keep it stable; changing it may make existing encrypted tokens unreadable.

AI or image request fails

Try a shorter prompt, a smaller supported image, and another module if appropriate. Some models or external providers may not be configured or available.

Still stuck?

Send the exact error text, the page URL, and steps to reproduce it to the project maintainer. Remove session cookies, API tokens, email addresses, and other secrets first.
